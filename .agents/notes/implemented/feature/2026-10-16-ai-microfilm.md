# Agent Note: AI 微电影优先工作流

Status: implemented

## Problem
现有开发入口强制经过故事引擎、分集地图和短剧节奏候选，初始化默认竖屏；单篇电影缺少明确入口。

## Decision
沿用十一技能和既有文件协议，以单篇横屏为新项目默认；每个技能独立提供微电影分支。开发直接在创作简报中交接全片结构，镜头与剪辑围绕人物选择、空间和声音组织。既有项目不自动迁移，显式连续剧请求仍走分集流程。

## Alternatives considered
只改 README 的成本最低，但无法改变技能行为。全量重命名可统一术语，但会破坏旧项目、独立安装和解析器，因此保留 short-drama、EP001 和原文件名。

## Consequences
新项目少做无用分集规划；旧协议仍可用。内部仍显示 EP001，文档必须解释它是整片容器。测试覆盖默认值与显式连续剧参数，内容质量需行为复测，不能以字符串测试代替。
