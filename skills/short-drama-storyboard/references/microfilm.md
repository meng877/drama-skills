# 微电影分镜与可生成性

**craft_default · FILM-06**：先明确场次中的观众视点、人物位置、行动轴线、出入口、视线与光线方向，再选择镜头。建立空间可以用全景、动作或声音，不强制固定覆盖套餐。

每镜沿用既有字段，职责写清它如何推进理解或情绪。起终状态交接人物站位、朝向、双手、持物、光线与运动方向；参考图沿用 IMG / PLAN / REF 边界。

先按表演、反应和声音确定叙事时长，再在模型已声明的原生区间内拆生成片段。模型未定时不猜限制。复杂长镜头、多人物交互、手部交接和群体动作列明风险，可用反应镜、插入镜、画外声或分段匹配动作完成同一戏剧职责；改变故事时回交剧本 owner。

分镜声明时长与视频提示词时长保持一致；生成时长与最终剪辑可用时长不同，素材余量和实际入出点由剪辑记录，不修改上游时长掩盖差异。

**reviewed_invariant · FILM-07**：检查知情时机、轴线与视线衔接、动作接续和全片时长是否可实现。
**taste_option**：远景、固定镜头、长停留与快剪都按叙事选；不默认 2.5 秒平均镜长或近景比例。
